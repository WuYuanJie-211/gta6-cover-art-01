# gta6-cover-art-01

GTA 6-style cover art maker: turn your photos and a caption into a multi-panel Vice City sunset poster, exported as a PNG (1080×1080, 1080×1350, 1920×1080). Static files under `app/`, fully offline — no network, no build step.
