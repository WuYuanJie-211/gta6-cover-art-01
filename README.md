# gta6-cover-art-01

GTA 6-style cover art maker: turn your photos and a caption into a multi-panel sunset poster, exported as a PNG (1080×1080, 1080×1350, 1920×1080). Static files under `app/`, fully offline — no network, no build step.

Sample photos: `app/samples/boulevard.jpg` and `pier.jpg` were made for make.fun with an image model; `sunset.jpg` is a sunset beach photo from Pexels (free to use, no attribution required). All three ship as the demo state.
